# 10. Edit Distance

Return the minimum number of insert, delete or replace operations needed to turn `word1` into `word2`.

### Example 1:
```
Input: word1 = "horse", word2 = "ros"
Output: 3
Explanation: horse -> rorse -> rose -> ros
```

### Constraints:
* `0 <= word1.length, word2.length <= 500`
