# 15. Number of Islands

Given a grid of `"1"` (land) and `"0"` (water), count the connected islands. Connections are horizontal and vertical only.

### Example 1:
```
Input: grid = [
  ["1","1","0"],
  ["1","0","0"],
  ["0","0","1"]
]
Output: 2
```

### Constraints:
* `1 <= grid.length, grid[i].length <= 300`
